# 💢 VASCOTECA
A Vascoteca é um sistema de gerenciamento de dados históricos e atuais do Club de Regatas Vasco da Gama. Desenvolvido em Python, o projeto permite organizar informações sobre jogadores, ídolos e conquistas, garantindo a integridade dos dados através de testes automatizados.

🚀 Funcionalidades
Gestão de Ídolos: Adicione, edite e remova as lendas do clube.

Painel de Títulos: Cadastro e consulta da nossa sala de troféus.

Elenco: Controle de jogadores ativos.

Hino: Execução do hino oficial do clube diretamente pelo terminal.

Qualidade Garantida: Suíte de testes robusta utilizando Pytest para assegurar que cada função funcione como deveria.

🛠️ Tecnologias Utilizadas
Python 3

Pytest (Testes Unitários)
